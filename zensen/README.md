# ZENSEN 前線

読んで、溜めて、押し上げる。
将棋の「読み」と、カードバトルの「エナジー管理・デッキ回し」を 1 つの盤にまとめた、1 局 5 分前後の戦略ボードゲームです。相手は 10 段階の AI。

**https://raw.githack.com/maoitenishi/drill/main/zensen/index.html**

## ルール（5×7 の盤）

- **勝ち方は 2 つ** — 相手の王を**詰ます**か、相手の最奥の段に駒を入れて 1 手番を生き延びさせる**突破**を 3 本。
- **1 手番に 1 つだけ** — 配置（手札を盤に置く）／移動（重ねれば取る）／溜め（何もしない）。
- **エナジー** — 手番ごとに +1、上限 8。配置はコストを払う。移動は無料。
- **前線** — 置けるのは自陣 2 段と、味方の駒の前後左右。前に出た駒が援軍の足場になる。
- **手札** — 8 枚のデッキから 4 枚。使った札は山の底へ。相手の使った札を覚えていれば、次に来る札が読める。
- **決戦** — 61 手目からエナジー回復 2 倍。100 手で判定（突破の数 → 盤上の駒のコスト）。

| 駒 | コスト | 動き |
|---|---|---|
| 王 | — | 全方向に 1 マス |
| 兵 | 1 | 前に 1 マス。敵陣 2 段に入ると「精」に成る |
| 盾 | 2 | 前後左右に 1 マス。同じ列の正面からは取られない |
| 槍 | 2 | 前へ何マスでも。後ろに 1 マス |
| 弓 | 3 | 前後左右に 1 マス（動いては取れない）。2 マス先の前・斜め前を動かずに射抜く |
| 騎 | 3 | 桂馬跳びで 8 方向 |
| 鷹 | 3 | 斜めに何マスでも |
| 龍 | 5 | 縦横に何マスでも ＋ 斜め 1 マス |
| 雷 | 4 | 術。王を除く敵駒をひとつ消す |

## 使う力

| | この遊びの中で |
|---|---|
| 先読み（計画） | 自分と相手の手を頭の中で進める。詰みと突破の 2 つの筋を同時に読む |
| 記憶（ワーキングメモリ） | 相手の手札の巡りを覚える。「記憶モード」では相手の手札が伏せられる |
| 我慢（抑制） | 今使うか、溜めて大駒を出すか。相手の「雷」が切れるまで龍を出さない |
| 切り替え（柔軟性） | 攻めの途中で受けに回る。狙いを詰みから突破へ変える |

脳トレ系のゲームが日常の認知機能まで底上げするかは、研究でも結論が分かれています。
これは治療や訓練効果を約束するものではなく、考える時間を楽しく積むための道具です。

## 収録

- **対局** — 足軽ハチ（Lv.1）から名人・無明（Lv.10）まで。下から順に勝つと次が開く。手番・早指し（30 秒／15 秒）・記憶モードを選べる
- **振り返り** — 終局後、自分の手を 1 手ずつ読み直して「読みの精度」と山場の一手（最善手との比較）を示す
- **詰め道場** — 1 手詰・3 手詰・5 手詰。自己対戦の棋譜から掘り出した、初手がただ 1 つの問題だけを収録
- **ヒント・待った** — 使った対局は昇格の対象外
- **記録** — 段位、戦績、連続日数、読みの精度。端末の中（localStorage）にだけ残る
- **通信不要** — Service Worker が殻を保管する。2 回目からは圏外でも起動する

## ファイル

| | |
|---|---|
| `index.html` | 画面の骨組みと見た目 |
| `engine.js` | ルール、局面評価、探索（反復深化 αβ・置換表）。画面／Worker／Node で共用 |
| `brain.js` `worker.js` | 思考の窓口。AI の手、ヒント、振り返り、詰めの判定を Worker で走らせる |
| `ui.js` | 盤と駒の描画、演出、効果音（Web Audio で合成。音源ファイルなし） |

| `puzzles.js` | 詰め問題（`dev/genpuzzles.js` の出力） |
| `dev/` | 調整に使った道具。配信には不要 |

## 調整のしかた（dev/）

ルールと強さは、AI 同士の自己対戦の数字を見て決めています。Node だけで動きます。

```bash
node dev/selfplay.js 200 3 3      # 同じ深さ同士 200 局：先後の勝率、決着の内訳、手数
```

```bash
node dev/ladder.js 60 4 3         # Lv.5 対 Lv.4 を 60 局：段差が急すぎないか
```

```bash
node dev/genpuzzles.js 400 101 > out.json   # 詰め問題を掘る（初手が一意のものだけ）
```

```bash
node dev/test.js                  # ルールの回帰テスト
```

採用時の数字（深さ 3 同士・300 局）：先手 46%／後手 54%、決着は詰み 31%・突破 42%・判定 27%、中央値 77 手。
深さ 4 は深さ 2 に 20 戦 19 勝 — 読むほど勝てる。
