# 仮説ドリル

事業責任者（本部長・取締役クラス）の視座で仮説を立てる訓練をするアプリです。
毎朝 10 分前後、90 秒 × 4 種目。各種目のあとに 30 秒ほどの振り返りがあります。

**https://raw.githack.com/maoitenishi/drill/main/index.html**

## 種目

| | 種目 | 制限 | 入力 |
|---|---|---|---|
| ① | 仮説10本ノック | 90秒 | 原因仮説を最大10行（Enter で次行） |
| ② | Why×5 高速分解 | 90秒 | 前段を引用しながら5段 |
| ③ | 仮説→検証セット | 90秒 | 仮説3件 × 検証手段 |
| ④ | 結論ファースト | 90秒 | つまり / だから / 何がわかれば判断が変わるか |

お題は内蔵の100問（①34・②33・③33。④は①③から流用）から出ます。
どれも規模と数値が具体的で、「伸びているのに悪化している」型の一見矛盾する事実を含んでいます。

## 振り返りと自己採点

時間が切れてから、自分の答えを見直します。

- ① 各行に視点（顧客・競合・自社・財務・組織・外部）を付け、経営会議に持っていく 3 本に★
- ②〜④ 種目ごとの自己チェック
- そこから自己採点を出し、履歴では①の視点の偏りを集計する
- ホームには「今日の意識点」を 1 つだけ出す。同じお題での再挑戦もできる

## 設計上の約束

- **負荷を下げない** — 練習中はヒント・例示・入力補完を一切出さない。
  画面にあるのはお題・残り秒数・入力欄だけ
- **即時性** — ホームの1タップでタイマーが走る。設定画面を挟まない
- **必ず記録が残る** — 時間切れで未確定の1行も保存する
- **通信不要** — React・Recharts・Tailwind は同梱済み。
  Service Worker が殻を保管するので2回目からは圏外でも起動する

## ホーム画面に追加

スマホでこの URL を開くと、ホーム画面に追加する導線が出ます。
追加すると全画面で起動し、アドレスバーが消えます。

- Android / PC Chrome … 「追加」ボタン
- iOS Safari … 共有ボタン →「ホーム画面に追加」

## 記録

記録はブラウザの中（localStorage）に残ります。端末ごとに別で、外には出ません。
